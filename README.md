# 针对黄油套娃压缩的解压工具

## 介绍

- 因为某些good资源在中国大多存储在网盘中，而为了应对过国内网盘的扫描，上传者不得不将好东西进行多重压缩，在rar、zip、图片格式上套了又套。我们下载后解压真切感觉难受啊，手动解压到目瞪口呆（我试过解压8重的）。所以，我搞了个工具来自动解套。

## 叠甲

- 因为套娃情况很多，我暂时只在windows11系统下试了一些资源（rar、zip、图片互套）
- 对于分卷压缩的文件暂不支持，需要你先把分卷压缩的文件解压一遍。该功能后面我玩到相关黄油再更新。
- 当前还未设置快捷运行，需要在项目cmd运行cargo来跑程序，使用说明看后边。
- 我先上传个可用的，后续个人不定期完善更新，具体看情况和需求。

## 运行依赖

1. **7-Zip**: 本工具依赖 7-Zip 命令行工具进行解压操作
   - 请确保系统中已安装 7-Zip（下载地址 https://www.7-zip.org/ ）
   - 确保 `7z.exe` 在系统环境变量 PATH 中
2. **Rust环境**

## 使用说明

1. 要解压的文件单独放在一个文件夹中
2. 在该项目代码本地目录下运行cmd窗口
3. 在cmd窗口中运行命令   cargo run -- "你要解压的黄油文件的路径"
4. 解压过程中注意不要关闭cmd窗口，解压完成后会显示“解压流程完成”字样

## 错误处理

- 如果出现 "7z command not found" 错误，请检查 7-Zip 是否正确安装并添加到环境变量
- 如果解压失败，请检查：
  1. 压缩文件是否完整
  2. 是否有正确的访问权限
  3. 目标目录是否有足够空间
  4. 密码是否正确（如果需要）
